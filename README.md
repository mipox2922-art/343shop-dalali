| **Picha & Printi** | Custom photo print, canvas wall art |
| **Logo & Branding** | Logo design pack, full brand kit |
| **Vitabu** | Storybooks (Kiswahili), author paperback |

## Kuendesha

```bash
cp .env.example .env
npm install
npm start          # http://localhost:3000
```
